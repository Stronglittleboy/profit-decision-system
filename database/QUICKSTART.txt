Day 1 上午 DBA任务 - 快速执行指南
=====================================

执行步骤（3分钟完成）
---------------------

1. 启动MySQL容器
   cd /home/hlw/work/code/profit-decision-system
   docker compose up -d profit-mysql
   
   等待30秒让MySQL完全启动

2. 安装MySQL客户端（如果未安装）
   sudo apt-get install mysql-client

3. 执行DBA任务
   cd /home/hlw/work/code/profit-decision-system/database
   ./day1-dba-tasks.sh

4. 验证执行结果
   ./verify-dba-tasks.sh

故障排查
--------
问题：无法连接数据库
解决：docker compose logs profit-mysql
     检查容器是否正常运行

问题：权限不足
解决：sudo usermod -aG docker $USER
     重新登录

问题：表已存在
解决：先备份，然后删除旧表重新创建
