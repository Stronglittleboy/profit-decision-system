# counterparty 页面 DSL

## 页面目标

提供往来方（客户/供应商）列表管理能力，包括查询、新增、编辑、删除和启停。本页面是主数据管理的第二个模块，复用 `account_subject` 相同模式（扁平列表替代树形）。

## 数据源

| 数据源 | 说明 |
|--------|------|
| 后端接口 | `/api/counterparty` |
| 数据表 | `counterparty` |
| 字典 | `counterparty_type`（往来方类型）、`credit_level`（信用等级） |

## 字段 DSL

| 字段 | 组件类型 | 必填 | 校验规则 | 新增时 | 编辑时 |
|------|---------|------|---------|--------|--------|
| name | el-input | 是 | 1-100 字符 | 可编辑 | 可编辑 |
| type | el-select | 是 | 枚举值 `customer/supplier/both` | 可编辑 | 可编辑 |
| contact | el-input | 否 | 0-100 字符 | 可编辑 | 可编辑 |
| phone | el-input | 否 | 0-20 字符 | 可编辑 | 可编辑 |
| address | el-input | 否 | 0-200 字符 | 可编辑 | 可编辑 |
| taxNo | el-input | 否 | 0-50 字符 | 可编辑 | 可编辑 |
| creditLevel | el-select | 否 | 枚举值 `A/B/C/D` 或为空 | 可编辑 | 可编辑 |
| enabled | el-switch | — | 默认 true | 默认开启 | 表格行内切换 |
| remark | el-input(textarea) | 否 | 0-200 字符 | 可编辑 | 可编辑 |

## 交互规则

### 查询
- 输入关键字后按回车或点击"查询"触发搜索（模糊匹配 name / contact / phone）
- 可通过类型下拉筛选 customer / supplier / both / 全部
- 搜索时列表展示 loading
- 无结果时展示 el-empty

### 新增
- 点击"新增往来方"打开空表单弹窗

### 编辑
- 点击行操作列"编辑"，加载当前行数据到弹窗

### 删除
- 二次确认弹窗，确认文案：`确认删除往来方「{name}」？`
- 后端返回"存在关联记录"时前端展示错误提示（预留）

### 启停
- 表格行内 Switch 组件直接切换
- 切换时 Switch 置为 disabled 防止重复点击
- 失败时自动回滚 Switch 视觉状态

## 页面约束

1. 所有异步操作期间对应的触发按钮必须置为 loading/disabled
2. 弹窗关闭后必须清空表单和校验状态
3. 必须有完整的加载/错误/空状态处理
4. 列表默认按创建时间倒序
