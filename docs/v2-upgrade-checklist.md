## 三、API 变更清单

### 3.1 安全修复

| 接口 | 方法 | 当前实现 | V2 变更 | 影响 |
|------|------|----------|---------|------|
| `/api/analysis/customer-rank` | GET | 字符串拼接 `startDate`/`endDate` | 1) 日期格式校验（`yyyy-MM-dd`）<br>2) 使用 `JdbcTemplate` 参数绑定<br>3) 非法日期返回 `ApiResponse` code=400 | **破坏性**：非法日期从静默执行改为拒绝 |

**实现示例**：

```java
// 当前（不安全）
String dateCond = "";
if (startDate != null) dateCond += " AND fe.business_date >= '" + startDate + "'";

// V2（安全）
List<Object> params = new ArrayList<>();
String dateCond = "";
if (startDate != null) {
    if (!startDate.matches("\\d{4}-\\d{2}-\\d{2}")) {
        throw new BusinessException(400, "日期格式须为 yyyy-MM-dd");
    }
    dateCond += " AND fe.business_date >= ?";
    params.add(startDate);
}
// 使用 jdbc.query(sql, params.toArray(), rowMapper)
```

### 3.2 新增接口（可选）

| 接口 | 方法 | 用途 | 返回 | Epic |
|------|------|------|------|------|
| `/api/meeting/summary` | GET | 会议清单数据（若不复用 dashboard） | 逾期笔数、待收余额、待决策列表 | E7 |

**注**：E7 默认形态 B 可直接复用 `GET /api/dashboard/summary` 已有字段，无需新增接口。

### 3.3 无变更接口

以下接口保持不变，仅前端调用方式调整：

- `GET /api/dashboard/summary` — 首页数据源

### 10.2 关键文案速查

**口径块精简版（§6）**：

> 经营利润相关数字主要来自「收支记录」中的已确认事实（`fact_event`，状态为有效）。应收账款 / 应付账款记录的是合同与收付执行层面的资金占用与到期情况，不自动等同于当期损益确认；同一业务既记经营事实又记应收应付时，请遵循贵司财务制度，避免重复计入利润。如有疑问请咨询财务负责人。

**免责声明（§5.1）**：

> 本系统展示的经营数字来源于业务录入与系统内聚合规则，不构成审计报告、纳税申报或对外融资材料的唯一依据。对外披露前请经财务及相关授权人员复核。

**客户分析用途说明（§5.2 文案 A）**：

> 本排名用于识别客户贡献结构与费用匹配度，支撑资源投入与改善讨论；不作为绩效考核或奖惩的唯一依据。

**客户分析页脚（§5.2 文案 B）**：

> 数据来自已确认的收支事实；若与合同/回款记录不一致，以财务核对结论为准。
