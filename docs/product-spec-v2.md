## 1. Definition of Done（会议目标「达成」判据）

同时满足下列 **6 条**，视为 **V2 MVP 会议目标达成**（可进入演示/内测）：

1. **P0-SEC-1 关闭**：`/api/analysis/customer-rank` 日期条件**仅允许参数绑定**，禁止字符串拼接进 SQL；非法日期不得执行危险 SQL（见 §12 与当前 HTTP 约定）。

5. **客户分析页**：页眉**用途说明** + 页脚**非奖惩声明**（文案见 §5.2）。  
6. **首页钻取 MVP**：从首页至少 **2 类**可点击区域跳转到带 query 的列表页（见 §4 E3，与 [`HomeView.vue`](../frontend/src/views/HomeView.vue) 对齐）。

## 4. 用户故事与验收标准

### E0 — 客户排名接口安全

**US-E0-1** 作为系统，我不接受未校验的日期片段进入 SQL，以免注入与数据篡改。

**AC**

- 当 `startDate`、`endDate` 均为空时，查询行为与现网一致（不加日期条件）。  
- 当任一参数非空且**非** `yyyy-MM-dd` 时：不得拼接进 SQL；返回 **`ApiResponse` 且 `code=400`**，`message` 含「日期格式」。  
- **HTTP 状态约定（与现网对齐）**：[`GlobalExceptionHandler`](../backend/src/main/java/com/profit/common/exception/GlobalExceptionHandler.java) 对 `BusinessException` 除 `code==401` 外默认 **HTTP 200 + body.code**。非法日期若抛 `BusinessException(400, …)`，则验收以 **`response.data.code === 400`** 为准；**技术债**：后续可统一改为 HTTP 400。  
- SQL 必须使用 **`JdbcTemplate` 可变参数**或 `NamedParameterJdbcTemplate`，禁止 `dateCond += " ... '" + startDate + "'"`。  
- 回归：`api-test.sh`（或等价）增加「非法日期 → body.code=400」用例。

## 12. API 契约 — `GET /api/analysis/customer-rank`

**路径**：`/api/analysis/customer-rank`  
**方法**：GET  
**鉴权**：与其它 API 相同，需登录 Token。

### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | string | 否 | `yyyy-MM-dd` |
| endDate | string | 否 | `yyyy-MM-dd` |

### 成功响应

- **HTTP**：200  
- **Body**：`ApiResponse<List<CustomerRankVO>>`，`code=0`，`data` 为排名列表（结构与现网一致）。

### 失败响应（非法日期）

- **实现建议**：抛 `BusinessException(400, "日期格式须为 yyyy-MM-dd")`。  
- **当前全局处理**：`BusinessException` 非 401 时 **HTTP 200**，`body.code=400`，`body.message` 为错误说明。  
- **前端验收**：axios 成功分支中若 `data.code===400`，应 `ElMessage.error` 并**不**刷新表格为脏数据。

### 安全要求

- SQL 中日期条件仅允许 `?` 绑定，禁止字符串拼接用户输入。
