# fact_event 页面 DSL

## 页面目标

提供收支事实的录入和查询能力。这是系统的核心数据入口，支持收入和成本两种类型的事实录入，不允许物理删除，只能冲正。

## 数据源

| 数据源 | 说明 |
|--------|------|
| 后端接口 | `/api/fact-event` |
| 数据表 | `fact_event` |
| 依赖 | `account_subject`（科目选择）、`counterparty`（往来方选择） |

## 字段 DSL

| 字段 | 组件类型 | 必填 | 校验规则 |
|------|---------|------|---------|
| type | el-radio-group | 是 | income / cost |
| amount | el-input-number | 是 | > 0，精度 2 位小数 |
| businessDate | el-date-picker | 是 | 有效日期 |
| accountingDate | el-date-picker | 是 | 有效日期，默认 = businessDate |
| subjectId | el-select (远程搜索) | 是 | 必须选择已有科目 |
| counterpartyId | el-select (远程搜索) | 是 | 必须选择已有往来方 |
| costCategory | el-select | 仅成本 | fixed/variable/direct/indirect |
| invoiceNo | el-input | 否 | 0-50 字符 |
| remark | el-input(textarea) | 否 | 0-500 字符 |

## 交互规则

### 查询
- 支持按类型（收入/成本/全部）、状态（有效/已冲正/全部）、日期范围筛选
- 列表默认按业务日期倒序
- 金额列按类型着色：收入绿色，成本红色
- 已冲正行灰色显示

### 新增
- 选择"收入"时隐藏成本类别字段
- 选择"成本"时显示成本类别字段
- 科目和往来方通过下拉远程搜索选择
- 会计日期默认跟随业务日期，可单独修改

### 冲正（替代删除）
- 点击"冲正"后二次确认
- 确认文案：`确认冲正这笔 ¥{amount} 的{type}记录？冲正后不可恢复。`
- 冲正后状态变为 reversed，该行显示为灰色
- 已冲正的行不展示冲正按钮

## 页面约束

1. 不提供"删除"操作，只有"冲正"
2. 事实一旦创建不可编辑（金额、日期等核心字段不可改）
3. 所有金额显示保留两位小数
4. 列表需展示关联的科目名称和往来方名称（后端在 VO 中翻译）
