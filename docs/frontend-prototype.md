## 🎨 设计规范

### 颜色方案
```css
/* 主色调 */
--primary-color: #1890ff;      /* 蓝色 */
--success-color: #52c41a;      /* 绿色 */
--warning-color: #faad14;      /* 橙色 */
--error-color: #f5222d;        /* 红色 */

/* 文字颜色 */
--text-primary: #262626;       /* 主要文字 */
--text-secondary: #8c8c8c;     /* 次要文字 */
--text-disabled: #bfbfbf;      /* 禁用文字 */

/* 背景颜色 */
--bg-white: #ffffff;           /* 白色背景 */
--bg-gray: #fafafa;            /* 灰色背景 */
--border-color: #d9d9d9;       /* 边框颜色 */
```

### 字体规范
```css
/* 字体大小 */
--font-size-large: 16px;       /* 大号字体 */
--font-size-base: 14px;        /* 基础字体 */
--font-size-small: 12px;       /* 小号字体 */

/* 字体粗细 */
--font-weight-bold: 600;       /* 粗体 */
--font-weight-normal: 400;     /* 正常 */
```

### 间距规范
```css
/* 间距 */
--spacing-xs: 4px;
--spacing-sm: 8px;
--spacing-md: 16px;
--spacing-lg: 24px;
--spacing-xl: 32px;
```

## 🎯 交互规范

### 按钮状态
- **默认：** 蓝色背景，白色文字
- **悬停：** 深蓝色背景
- **点击：** 更深蓝色背景
- **禁用：** 灰色背景，灰色文字

### 表单验证
- **必填项：** 红色星号标记
- **错误提示：** 红色文字，输入框红色边框
- **成功提示：** 绿色文字

### 加载状态
- **加载中：** 显示 Loading 动画
- **加载失败：** 显示错误提示
- **空数据：** 显示"暂无数据"
