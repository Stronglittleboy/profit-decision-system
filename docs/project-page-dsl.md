# project 页面 DSL

## 页面目标

项目管理页面。支持项目的创建、编辑、状态流转、启停管理，以及后续的项目盈亏查看入口。

## 数据源

| 数据源 | 说明 |
|--------|------|
| 后端接口 | `/api/project` |
| 数据表 | `project` |

## 字段 DSL

| 字段 | 组件类型 | 必填 | 校验规则 |
|------|---------|------|---------|
| code | el-input | 是 | 1-50 字符，全局唯一 |
| name | el-input | 是 | 1-100 字符 |
| budget | el-input-number | 是 | ≥ 0，精度 2 位小数 |
| startDate | el-date-picker | 否 | 有效日期 |
| endDate | el-date-picker | 否 | 有效日期，≥ startDate |
| manager | el-input | 否 | 0-50 字符 |
| description | el-input(textarea) | 否 | 0-500 字符 |

## 列表列定义

| 列 | 宽度 | 特殊渲染 |
|----|------|---------|
| 编号 (code) | 140 | 固定色 |
| 名称 (name) | flex | - |
| 状态 (status) | 100 | Tag 颜色区分 |
| 预算 (budget) | 140 | 格式化金额 |
| 起止日期 | 200 | `startDate ~ endDate` |
| 经理 (manager) | 100 | - |
| 启用 | 70 | Switch |
| 操作 | 200 | 编辑 / 状态流转 / 删除 |

## 状态 Tag 颜色

| 状态 | Tag 类型 | 标签 |
|------|---------|------|
| planning | warning | 规划中 |
| executing | success | 进行中 |
| completed | info | 已完成 |
| suspended | danger | 已暂停 |

## 状态流转操作按钮

| 当前状态 | 可用操作 | 按钮文字 |
|---------|---------|---------|
| planning | start | 启动 |
| executing | complete, suspend | 完成, 暂停 |
| suspended | resume | 恢复 |
| completed | 无 | - |

## 交互规则

### 查询
- 支持关键字搜索（匹配编号或名称）
- 支持按状态筛选
- 默认按创建时间倒序

### 新增/编辑
- 编辑时 `code` 不可修改
- 如果填了 endDate，则必须 ≥ startDate

### 状态流转
- 点击状态操作按钮后二次确认
- 确认文案：`确认将项目「{name}」{操作描述}？`

### 删除
- 已完成项目不可删除（按钮置灰或隐藏）
- 确认文案：`确认删除项目「{name}」？删除后不可恢复。`

### 启停
- 使用 Switch 开关，切换时调用启停接口
