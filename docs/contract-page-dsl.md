# contract 页面 DSL

## 页面目标

合同管理页面。支持合同的创建、编辑、状态流转（草稿→生效→完成/终止）和查询。关联往来方和项目。

## 数据源

| 数据源 | 说明 |
|--------|------|
| 后端接口 | `/api/contract` |
| 数据表 | `contract` |
| 依赖 | `counterparty`（签约方选择）、`project`（项目选择，可选） |

---

## 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│  ContractView                                                 │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  搜索栏：[关键字] [类型▼] [状态▼] [搜索] [重置] [新增]  │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  列表                                                   │  │
│  │  编号 | 名称 | 类型 | 往来方 | 金额 | 签约日 | 状态 | 操作│  │
│  └────────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  新增/编辑弹窗                                          │  │
│  │  编号 / 名称 / 类型 / 往来方 / 项目 / 金额 /            │  │
│  │  签约日 / 生效日 / 到期日 / 备注                         │  │
│  └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

## 字段 DSL

| 字段 | 组件类型 | 必填 | 校验规则 |
|------|---------|------|---------|
| code | el-input | 是 | 1-50 字符，唯一 |
| name | el-input | 是 | 1-200 字符 |
| counterpartyId | el-select(远程搜索) | 是 | 必须选择 |
| projectId | el-select(远程搜索) | 否 | - |
| type | el-select | 是 | sales/purchase/service |
| amount | el-input-number | 是 | > 0, 精度 2 位 |
| signDate | el-date-picker | 否 | - |
| startDate | el-date-picker | 否 | - |
| endDate | el-date-picker | 否 | ≥ startDate |
| remark | el-input(textarea) | 否 | 0-500 字符 |

---

## 状态 Tag & 操作按钮

| 状态 | Tag类型 | 可用操作 |
|------|---------|---------|
| draft | warning | 编辑, 生效, 终止, 删除 |
| active | success | 完成, 终止 |
| completed | info | 无 |
| terminated | danger | 无 |

---

## 交互规则

- 已完成/已终止合同：编辑和删除按钮不显示
- 状态流转前二次确认
- 金额列格式化为 ¥xxx,xxx.xx
- 往来方和项目通过下拉搜索选择
