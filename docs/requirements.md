## 1. 项目概述

### 1.1 项目背景
企业经营过程中面临的核心问题：
- 不清楚钱花在哪里、赚在哪里
- 无法准确评估各部门/项目的盈利能力
- 缺少数据支撑的决策建议
- 预算执行缺乏监控

### 1.2 项目目标
构建一个基于**事实 → 归因 → 指标 → 决策**的闭环系统，实现：
- 精准的成本归因和利润核算
- 实时的经营指标监控
- 智能的决策建议生成
- 有效的预算管理和执行跟踪

### 1.3 目标用户
- **财务人员**：录入收入/成本、查看报表
- **部门经理**：查看本部门经营数据、执行决策建议
- **高层管理者**：查看全局经营状况、制定目标
- **项目经理**：跟踪项目盈亏

## 2. 核心业务场景

### 2.1 日常经营记录

**场景1：收入确认**
```
用户：财务人员
操作：录入一笔销售收入
输入：
- 客户：客户A
- 金额：50,000 元
- 业务日期：2026-05-10（签合同）
- 会计日期：2026-05-15（确认收入）
- 发票号：12345678
- 归属部门：销售部
- 归属项目：项目X

系统处理：
1. 创建 FactEvent（type=income）
2. 触发归因：直接归属到销售部和项目X
3. 更新当月指标
```

**场景2：成本录入（固定成本）**
```
用户：财务人员
操作：录入年度保险费
输入：
- 供应商：保险公司
- 金额：12,000 元
- 业务日期：2026-01-01
- 成本类别：固定成本
- 分摊方式：线性分摊
- 分摊期间：2026-01-01 至 2026-12-31

系统处理：
1. 创建 FactEvent（amortization_start/end）
2. 每日定时任务：生成当日分摊的 Attribution（1000元/月）
3. 更新各月指标
```

**场景3：成本录入（变动成本）**
```
用户：财务人员
操作：录入原材料采购
输入：
- 供应商：供应商B
- 金额：30,000 元
- 成本类别：变动成本
- 归属项目：项目X

系统处理：
1. 创建 FactEvent（cost_category=variable）
2. 触发归因：直接归属到项目X
3. 更新项目成本
```

### 2.2 预算管理

**场景4：预算编制**
```
用户：部门经理
操作：编制本月预算
输入：
- 部门：销售部
- 周期：2026-05
- 收入预算：100,000 元
- 固定成本预算：20,000 元
- 变动成本预算：30,000 元

系统处理：
1. 创建 Budget 记录（status=draft）
2. 提交审批
3. 审批通过后 status=approved
```

**场景5：预算执行监控**
```
用户：部门经理
操作：查看预算执行情况
展示：
- 收入：实际 80,000 / 预算 100,000 = 80% ⚠️
- 成本：实际 55,000 / 预算 50,000 = 110% ⚠️
- 预警：成本超标 10%
```

**场景6：预算调整**
```
用户：部门经理
操作：申请调整预算
输入：
- 原预算：50,000 元
- 新预算：60,000 元
- 调整原因：市场推广费用增加

系统处理：
1. 创建 BudgetAdjustment（status=pending）
2. 通知审批人
3. 审批通过后更新 Budget
```

  - 其他：10,000 元

### 2.4 决策支持

**场景9：查看决策建议**
```
用户：部门经理
操作：查看本月决策建议
展示：
问题1：成本超标 15%
- 根因：人力成本占比过高（60%）
- 建议：优化人员配置，考虑外包非核心业务
- 预期收益：降低成本 5,000 元/月
- 优先级：高
- 相关事实：查看 8 条人力成本支出明细

问题2：客户A贡献下降
- 根因：本月订单量减少 30%
- 建议：主动联系客户，了解需求变化
- 预期收益：挽回收入 20,000 元
- 优先级：中
```

**场景10：执行决策并记录**
```
用户：部门经理
操作：执行决策建议
输入：
- 选择建议：优化人员配置
- 执行动作：将2名员工调整到其他部门
- 执行时间：2026-05-20

系统处理：
1. 创建 ActionRecord
2. 下月自动对比：成本是否真的降低了？
3. 标记有效性：effective / ineffective
```

## 3. 功能需求

### 3.1 数据录入

#### 3.1.1 收入录入
- 必填：金额、业务日期、会计日期、客户、归属部门
- 可选：项目、发票号、税率、备注
- 支持批量导入（Excel/CSV）
- 支持 Agent 语义录入

#### 3.1.2 成本录入
- 必填：金额、业务日期、会计日期、成本类别、归属部门
- 可选：供应商、项目、发票号、分摊方式
- 成本类别：固定/变动/直接/间接
- 跨期分摊：支持设置分摊期间

#### 3.1.3 数据修正
- 支持冲正（创建 reversed 记录）
- 不允许直接删除，保留审计轨迹

### 3.2 预算管理

#### 3.2.1 预算编制
- 按组织单元 + 周期 + 类别编制
- 支持复制上期预算
- 支持智能推荐（基于历史数据）

#### 3.2.2 预算审批
- 预算提交后进入审批流程
- 审批通过后生效
- 支持审批意见

#### 3.2.3 预算执行监控
- 实时对比预算 vs 实际
- 超标预警（可配置阈值）
- 执行率统计

#### 3.2.4 预算调整
- 支持预算调整申请
- 需审批通过
- 保留调整历史

### 3.3 项目核算

#### 3.3.1 项目管理
- 创建/编辑/关闭项目
- 项目状态：计划中/执行中/已结项
- 项目预算设置

#### 3.3.2 项目盈亏
- 实时计算项目收入/成本/利润
- 预算执行率
- 成本结构分析

#### 3.3.3 项目对比
- 多项目利润率对比
- 项目排行榜

### 3.4 指标查询

#### 3.4.1 经营看板
- 当期收入/成本/利润
- 预算对比
- 目标对比
- 同比/环比

#### 3.4.2 成本分析
- 成本结构（饼图）
- 成本趋势（折线图）
- 成本明细（表格）

#### 3.4.3 客户分析
- 客户贡献排行
- 客户利润率
- 客户预警

### 3.5 决策支持

#### 3.5.1 问题识别
- 自动识别：成本超标、收入下降、利润率低
- 根因分析：关联具体事实

#### 3.5.2 建议生成
- 规则引擎：基于预设规则
- AI 引擎：基于历史数据（可选）
- 优先级排序

#### 3.5.3 执行跟踪
- 记录执行动作
- 评估执行效果
- 反馈到决策引擎

### 3.6 审批流程

#### 3.6.1 审批配置
- 配置审批规则（金额阈值、审批人）
- 支持多级审批

#### 3.6.2 审批处理
- 待审批列表
- 审批/驳回
- 审批意见

### 3.7 权限管理

#### 3.7.1 角色定义
- 管理员：全部权限
- 财务人员：录入数据、查看全局报表
- 部门经理：查看本部门数据、执行决策
- 项目经理：查看本项目数据
- 普通员工：只读权限

#### 3.7.2 数据权限
- 按组织单元隔离
- 上级可查看下级数据

## 4. 非功能需求

### 4.1 性能要求
- 数据录入响应时间 < 1s
- 报表查询响应时间 < 3s
- 支持 1000+ 并发用户

### 4.2 数据准确性
- 金额计算精度：小数点后 2 位
- 归因计算保证原子性（批次控制）
- 指标重算支持

### 4.3 安全性
- 所有操作记录审计日志
- 敏感数据加密存储
- 防止 SQL 注入、XSS 攻击

### 4.4 可用性
- 系统可用性 > 99.5%
- 数据备份：每日全量 + 实时增量

### 4.5 易用性
- 界面简洁直观
- 关键操作有引导提示
- 支持移动端访问
