# receivable / payable 页面 DSL

## 页面目标

两个对称页面：应收账款管理和应付账款管理。支持创建、登记回款/付款、逾期标记。

---

## 统一页面结构（Receivable / Payable 共用模式）

```text
┌──────────────────────────────────────────────────────────────┐
│  RecPayView (应收 / 应付)                                     │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  搜索栏：[关键字] [状态▼] [搜索] [重置] [新增]          │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  汇总卡片                                               │  │
│  │  [总额 ¥xxx] [已收/付 ¥xxx] [待收/付 ¥xxx] [逾期 x笔]  │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  列表                                                   │  │
│  │  编号|往来方|合同|总额|已收付|待收付|到期日|状态|操作      │  │
│  └────────────────────────────────────────────────────────┘  │
│  弹窗1：新增                                                  │
│  弹窗2：登记回款/付款（输入本次金额）                          │
└──────────────────────────────────────────────────────────────┘
```

---

## 字段 DSL（新增弹窗）

| 字段 | 组件 | 必填 |
|------|------|------|
| code | el-input | 是，唯一 |
| counterpartyId | el-select(filterable) | 是 |
| contractId | el-select(filterable) | 否 |
| amount | el-input-number | 是，> 0 |
| dueDate | el-date-picker | 是 |
| remark | el-input(textarea) | 否 |

## 登记回款/付款弹窗

| 字段 | 组件 | 校验 |
|------|------|------|
| payAmount | el-input-number | > 0，≤ 剩余金额 |

---

## 状态 Tag

| 状态 | Tag | 标签 |
|------|-----|------|
| pending | warning | 待收/待付 |
| partial | '' (default) | 部分 |
| paid | success | 已结清 |
| overdue | danger | 逾期 |

## 操作按钮

| 状态 | 可用操作 |
|------|---------|
| pending/partial | 登记回款, 标记逾期, 删除 |
| overdue | 登记回款, 删除 |
| paid | 无 |
