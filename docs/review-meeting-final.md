### ⚠️ 业务风险（按严重程度排序）

#### 🔴 P0 - 致命问题

**1. 成本分类缺失**
```
现状：cost 只有金额，没有分类
问题：无法区分固定成本/变动成本/直接成本/间接成本
影响：无法做盈亏平衡分析、边际贡献分析

业务场景：
- 房租（固定成本）→ 按时间分摊
- 原材料（变动成本）→ 按产量分摊
- 销售提成（直接成本）→ 直接归属
- 办公费用（间接成本）→ 按人头分摊

建议：
fact_event 增加 cost_category 字段
枚举值：fixed/variable/direct/indirect
```

**2. 收入确认时点不明确**
```
现状：event_time 既是业务时间，又是记账时间
问题：收入确认原则不清晰

业务场景：
- 5月1日签合同（合同时间）
- 5月10日发货（发货时间）
- 5月20日收款（收款时间）
→ 应该算哪个月的收入？

建议：
增加字段：
- business_date（业务发生日期）
- accounting_date（会计确认日期）
- cash_date（现金流日期，可选）

默认用 accounting_date 计算利润
```

**3. 跨期费用处理缺失**
```
问题：年度保险费、季度房租如何分摊？

业务场景：
- 1月1日支付全年保险 12000 元
- 应该分摊到 12 个月，每月 1000 元

建议：
fact_event 增加：
- amortization_start（分摊开始日期）
- amortization_end（分摊结束日期）
- amortization_method（分摊方式：linear/actual_days）

归因时自动按月分摊
```

#### 🟡 P1 - 重要问题

**4. 缺少预算管理**
```
现状：只有目标（goal），没有预算（budget）
区别：
- 目标：希望达到的结果（利润 5 万）
- 预算：计划的收入和支出明细

业务需求：
- 预算 vs 实际对比
- 预算执行率
- 预算调整审批流程

建议：
新增 budget 表：
- org_unit_id
- period
- category（收入类别/成本类别）
- budgeted_amount（预算金额）
- approved_by（审批人）
```

**5. 缺少客户/供应商维度**
```
现状：metadata 存客户信息，不规范
问题：无法分析客户贡献、供应商成本

业务需求：
- 客户利润贡献排行
- 供应商成本占比
- 客户信用管理

建议：
fact_event 增加：
- counterparty_type（对手方类型：customer/supplier）
- counterparty_id（对手方ID）

新增 counterparty 表（客户/供应商主数据）
```

**6. 缺少项目维度**
```
现状：org_unit 有 project 类型，但没有项目生命周期管理
问题：无法跟踪项目盈亏

业务需求：
- 项目预算 vs 实际
- 项目进度 vs 成本
- 项目结项核算

建议：
新增 project 表：
- name
- budget（预算）
- start_date / end_date
- status（planning/executing/closed）
- manager_id（项目经理）
```

#### 🟢 P2 - 优化建议

**7. 缺少发票管理**
```
业务需求：
- 收入要有发票号
- 成本要有发票验证
- 税务合规检查

建议：
fact_event 增加：
- invoice_no（发票号）
- invoice_date（开票日期）
- tax_rate（税率）
- tax_amount（税额）
```

**8. 缺少审批流程**
```
业务需求：
- 大额支出需要审批
- 预算调整需要审批
- 目标修改需要审批

建议：
新增 approval_flow 表
fact_event 增加 approval_status
```
